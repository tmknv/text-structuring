# Text Structuring — Мультиагентная система обработки текстов

## Назначение

Автоматическое структурирование неформализованных текстов с использованием мультиагентного подхода вместо монолитного обращения к LLM.

## Архитектура

### Основные компоненты

| Компонент | Назначение |
|-----------|-----------|
| **Pipeline** | Управляет последовательным выполнением агентов, передав state каждому |
| **TextState** | Центральный объект состояния, аккумулирующий результаты работы агентов |
| **BaseAgent** | Базовый класс для всех агентов (контракт: получает state → возвращает state) |
| **LLMClient** | Интеграция с OpenRouter API (OpenAI совместимый интерфейс) |
| **Prompts** | Специализированные промпты для каждого этапа обработки |

### Агенты

Последовательное выполнение в pipeline:

1. **Segmenter** 
   - Входные данные: raw_text (исходный текст)
   - Выходные данные: segments (список отдельных сегментов)
   - Задача: разбиение текста на логические единицы

2. **StructureBuilder**
   - Входные данные: segments
   - Выходные данные: structure (JSON с иерархией)
   - Задача: создание структурированного представления (title, sections и т.д.)

3. **Styler**
   - Входные данные: structure
   - Выходные данные: styled_text
   - Задача: форматирование текста согласно требованиям стиля

4. **Proofreader**
   - Входные данные: styled_text
   - Выходные данные: final_text
   - Задача: финальная проверка и корректировка ошибок

## Поток данных

```
Исходный текст
    ↓
[Segmenter] → segments
    ↓
[StructureBuilder] → structure (JSON)
    ↓
[Styler] → styled_text
    ↓
[Proofreader] → final_text
```

## Точка входа

[main.py](main.py):
- Инициализирует pipeline с набором агентов
- Создаёт TextState с исходным текстом
- Запускает pipeline.run(state)
- Обрабатывает результат
